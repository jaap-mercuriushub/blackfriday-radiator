# Evolar Black Friday – Slimme olieradiator WiFi

Landingspagina met een scroll-gestuurde 3D-productanimatie (three.js + GSAP ScrollTrigger) voor de
[Evolar slimme olieradiator 9 ribben, 2000W, taupe](https://www.evolarshop.nl/evolar-olieradiator-9-ribben-2000w-taupe-wifi).

- `index.html` – pagina-opbouw en content
- `styles.css` – Evolar-huisstijl (Montserrat, oranje #E8871E, navy)
- `main.js` – 3D-model, scroll-tijdlijn, countdown, stroomcalculator

Statische site: geen build nodig. Op Vercel deployt elke push naar `main` automatisch.
